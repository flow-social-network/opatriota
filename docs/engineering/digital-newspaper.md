# Jornal digital

O domínio deve separar edição, página, bloco, ordem, capa, sumário e versão publicada. Páginas de edição não são páginas institucionais.

Requisitos de persistência: edição publicada aponta para uma versão imutável; matérias/imagens usadas devem ser referenciadas pela versão aprovada; ordenação e metadados precisam sobreviver ao reload.

Estado atual: componentes administrativos existem, mas a cobertura real de CRUD, preview paginado, publicação e arquivo ainda não foi verificada ponta a ponta. Não considerar cards visuais como implementação concluída.
